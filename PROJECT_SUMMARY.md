# Post-Discharge Urgency Triage System — Executive Summary

The Post-Discharge Urgency Triage System is a human-in-the-loop clinical decision-support and operations platform engineered with a FastAPI/SQLite backend and a React/Tailwind CSS frontend to assist hospital staff in triaging incoming post-discharge psychiatric support requests. The system automatically evaluates patient-submitted message text against transparent, explainable keyword risk indicators (detecting safety concerns, severe distress, isolation, and queue wait times) to calculate a preliminary priority rating (LOW, MEDIUM, or HIGH) while keeping internal clinical scores strictly confidential from patients. Built around strict human oversight, the platform features a real-time clinical operations dashboard with synthesized Web Audio alert chimes for urgent cases, interactive priority confirmation and override controls, clinical staff assignment and callback scheduling, simulated multi-channel patient messaging (SMS/Email), formal case resolution and disposition tracking, immutable audit trails, and one-click reporting through CSV data exports and printable clinical dossiers.
